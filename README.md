# My Budget Tracker

## Overview

My Budget Tracker is a simple web application that helps users track their expenses in one place. The application allows users to enter expense details, categorize spending, and view expenses in a structured table. The project focuses on building strong HTML and CSS fundamentals while creating a clean and user-friendly interface.

## Features

* Add expense form with:

  * Expense name
  * Amount
  * Category selection
  * Date selection
* Expense table displaying:

  * Expense name
  * Amount
  * Category
  * Date
* Budgeting tips video section
* Instructions section explaining how to use the tracker
* Responsive design elements
* Professional styling using CSS
* Custom typography with Google Fonts
* Card-based layout using the CSS Box Model

## Technologies Used

* HTML5

* Google Fonts

## How to Run the Project

1. Download or clone the project files.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
